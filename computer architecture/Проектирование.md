## Пример
Сортировка массива пузырьком
1. Адресность (Трехадресная)
2. Архитектура (Гарвардская)

```mermaid
flowchart TD
id1([Начало]) --> Ввод_кол_чисел
Ввод_кол_чисел --> Ввод_чисел
Ввод_чисел --> Блок[i=0]
Блок[i=0] --> Блокif{" i<N "}
Блокif{" i<N "} --> id2([Конец])
Блокif{" i < N "} --> Бл[j=0]
Бл[j=0] --> if1{"j < N -i" }
if1{"j < N -i" } --> kj[i + 1]
kj[i + 1] --> Блокif{" i<N "}
if1{"j < N -i" } --> if2{" arr[j] < arr[j+1] "}
if2{" arr[j] < arr[j+1] "} --> swap
if2{" arr[j] < arr[j+1] "} --> j++
j++ --> if2{" arr[j] < arr[j+1] "}
```
Следовательно нужно:
- LTM - адрес в ячейке памяти; литерал
- LTR - адрес регистра; литерал
- 15 регистров

| 0   | 0       |
| --- | ------- |
| 1   | 1       |
| 2   | N       |
| 3   | i       |
| 4   | возврат |
| 5   | N-i     |
| 6   | j+1     |

- JL - адрес регистра 1  операнда; адрес регистра второго операнда; адрес перехода прилжа
- SUB - адрес регистра 1 операнда; адрес регистра 2 операнда; адрес результата
- ADD (как SUB)
- MTR - адрес регистра source, адрес регистра dest (memory to register)
- RTM

и тогда:
```mermaid
flowchart TD
id1([Начало]) --> B1[LTR 2, N]
B1[LTR 2 N] --> B2[LTM 0, R0]
B2[LTM0, R0] --> B3[LTM 1, R1]
B3[LTM 1, R1] --> B4[LTM N, R3]
B4[LTM N, R3] --> B5[LTE 3, 0]
B5[LTE 3, 0] --> B6[JL 3, 2, M0]
B6[JL 3, 2, M0] --> id2([Конец])
B6[JL 3, 2, M0] --> B7[LTR 4, 0]
B7[LTR 4, 0] --> B8[SUB 2, 3, 5]
B8[SUB 2, 3, 5] --> B9[JL 4, 5, m1]
B9[JL 4, 5, m1] --> B10[ADD 3, 1, 3]
B10[ADD 3, 1, 3] --> B11[JL 1, 0, m2]
B11[JL 1, 0, m2] --> B6[JL 3, 2, M0]
B9[JL 4, 5, m1] --> B12[MTR 4, 7]
B12[MTR 4, 7] --> B13[ADD 4, 1]
B13[ADD 4, 1] --> B14[MTR 6, 8]
B14[MTR 6, 8] --> B15[JL 7, 8, m3]
B15[JL 7, 8, m3] --> B16[RTM 6, 7]
B16[RTM 6, 7] --> B17[RTM 4, 8]
B17[RTM 4, 8] --> B18[ADD 4, 1, 4]
B15[JL 7, 8, m3] --> B18[ADD 4, 1, 4]
B18[ADD 4, 1, 4] --> B19[JL 1, 0, m4]
B19[JL 1, 0, m4] --> B9[JL 4, 5, m1]
```
