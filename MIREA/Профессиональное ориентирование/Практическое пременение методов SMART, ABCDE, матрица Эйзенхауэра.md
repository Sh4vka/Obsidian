Чтобы грамотно обращаться со временем в первую очередь стоит выявить причины, мешающие использовать его рационально.
- Прокрастинация, откладывание дел
- Перфекционизм, фанатичное стремление доведения задач до идеала
- Недостаток знаний в области, непозволяющий оперативно выполнить порученную задачу 
- Отсутствие навыка работы с инструментами и техниками тайм-менеджмента

# Матрица Эйзенхауэра 
Метод тайм-менеджмента, помогающий расставлять приоритеты

|          | Срочно                                 | Не срочно                              |
| -------- | -------------------------------------- | -------------------------------------- |
| Важно    | А (в первую очередь)                   | B (Потратить как можно больше времени) |
| Не важно | C (Потратить как можно меньше времени) | D (Удалить)                            |
Как пользоваться матрицей:
- Отследить в течении нескольких дней, какие задачи вы выполняете и сколько времени это займет 

### Квадрат А
Имеет самый высокий приоритет.
Делегировать нельзя.
Желательно держать пустым
Пример:
- Встреча с юристом.
- Подготовка к презентации
- Запись к стоматологу

### Квадрат B
Несрочные важные дела.
Встраивают в свой ежедневный распорядок.
Откладывать нежелательно 

### Квадрат C 
Помехи, суета, илюзия.
Любой ценой сокращать время выполнения этих задач
Пример:
- Поменять лампочку
- Отвести принтер в ремонт 

### Квадрат D 
Самые легкие и приятные, поэтому люди охотно выполняют во время "прокрастинации".
Преобладание таких задач сведетельствуют о проблемах с самодисциплиной.
Выполнять по остаточному принципу.
### Мнемоника правил 4D 
Do -делай 
Decide - планируй и обдумывай 
Delegate - делегируй 
Delete - удаляй

|          | Срочно   | Не срочно |
| -------- | -------- | --------- |
| Важно    | Do       | Decide    |
| Не важно | Delegate | Delete    |

### Зачем
- Расстановка приоритетов
- Планирование дел
- Делегирование
- Диагностика

## Преимущества и недостатки метода
Достоинства:
- **Универсальность**. Подходит для любых горизонтов планирования
- **Простота**.
Недостатки:
- **Субъективность**. Сортировка задач идет интуитивноне опираясь на обхективные критерии
- **Приоретизация без учета контекста**

# Метод ABCDE 
Техника планирования для и расстановки приоритетов.
- **Этап 1**. Составление списка дел.
- **Этап 2**. Разбивание задачи на 5 групп:

|     | Приоритет           | Последствия            | Описание            | Примеры |
| --- | ------------------- | ---------------------- | ------------------- | ------- |
| A   | Высокий             | Серьезные              | Влияют на будущее   |         |
| B   | Средние             | Средние                | Рутинные задачи     |         |
| C   | В последнюю очередь | Без последствий        | Необязательные дела |         |
| D   | Делегировать        | Любые                  |                     |         |
| E   | Не делать           | Впустую отнимают время |                     |         |
# SMART метод
- S - specific, конкретная
- M - measure, измеримая
- A - archievable, достижимая
- R - relevant, актуальная
- T - time-bound, Ограниченная по времени
### Specific 
Цель нужно сформулировать точно - так чтоб нельзя было трактовать двояко и не пришлось уточнять, что имелось в виду.

Неверно:
Исправить баг на сайте

Правильно: 
Конкретная ошибка связанная с почтой

Помогающие вопросы:
- Что не устраивает 
- Что необходимо сделать 
- Какой результат зочу получить

### Measurable 
Должен быть способ определить, достигнута цель или нет. Например значение показателя в цифрах которого нужно достич.

Неверно:
Собрать финансовую подушку

Правильно: 
Отложить 400 тысяч рублей

Помогающие вопросы:
- С помощью каких метрик можно измерить достижение цели
- Какие из возможных метрик выбрать и почему
- Как часто сверять с эталоном

### Achievable 
Если SMART цели нельзя достич с помощью имеющихся ресурсов значит она не соответствует этому критерию

Неверно:
Избавится от негативных отзывов

Правильно: 
Снизить количество негативных отзывов на 20%

Помогающие вопросы:
- Есть ли знания и ресурсы необхожимые для достижения цели
- Если знаний и ресурсов недостаточно то сколько времени потребуется для достижения

### Relevant
SMART цель не должна соотноситься с глобальной целью и не мешать ей а наоборот помогать достич ее.

Цель не помогает достичь глобальной цели:
- Собрать инфу о крупных дистрибьютерах

Помогает:
- Договориться с дистрибьютерами 

Помогабщие вопросы:
- Почему это важно 
- Что измениться от выполнения цели 

### Time-bound
У любой цели должен быть срок к которому ее нужно достичь

Помогающие вопросы:
- К какому времени необходимо получить результат.
- Какие факторы могут помешать выполнить цель в срок
