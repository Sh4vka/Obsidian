Rust - язык со статической типизацией. 
Все типы делятся на 2 группы: #скалярные и #составные 

#скалярные - одно значение.
**Целые**:
Со знаком: `i8` `i32` `i64` `isize` 
Без Знака: `u8`, `u32`, `u64`, `usize`

Существует раздилитель `_`  для чисел:
```rust
let a: i32 = -100; 
let b: u8 = 255; 
let c = 1_000_000;
```

**С плавающей точкой**: 
`f32` и `f64` (по умолчанию `f64`)
```rust
let x = 3.14; // f64 
let y: f32 = 2.0; // f32
```

**Булев тип**:
```rust
let t: bool = true; 
let f = false;
```

Символ **char** - Unicode
`let c = 'z';`

 Приведение типов из файла [[Функции]] 
 ```rust
 fn calc_damage(base: u32, multiplier: f64) -> u32 {
    (base as f64 * multiplier) as u32
}
 ```
 

#составные 
**Tuple** - фиксированный набор разных типов *(находится в стеке)*:
```rust
let tup: (i32, f64, bool) = (42, 3.14, true);

// Доступ по индексу
let x = tup.0; // 42
let y = tup.1; // 3.14

// Деструктуризация
let (a, b, c) = tup;
```


**Array** - Фиксированный набор одного типа *(находится в стеке)*:
```rust
let arr = [1, 2, 3, 4, 5];
let first = arr[0];
let len = arr.len();

// Инициализация одним значением: [значение; длина]
let zeros = [0; 5]; // [0, 0, 0, 0, 0]
```
**Деструктуризация** — это просто распаковка составного типа в отдельные переменные за одну строку:
```rust
let (name, hp, dmg) = enemy; // вместо enemy.0, enemy.1, enemy.2
```
