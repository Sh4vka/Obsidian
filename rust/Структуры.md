Struct — способ объединить связанные [[Типы данных|данные]] под одним именем.
**Объявление и создание**:
```rust
struct Player {
    name: String,
    hp: i32,
    level: u32,
    is_alive: bool,
}

let player = Player {
    name: String::from("Артём"),
    hp: 100,
    level: 1,
    is_alive: true,
};

println!("{} hp:{}", player.name, player.hp);
```

**Shorthand** — если имя переменной совпадает с полем:
```rust
let name = String::from("Артём");
let hp = 100;
let player = Player { name, hp, level: 1, is_alive: true };
//                    ^^^^  ^^ сокращение
```

**Struct update** — взять поля из другого экземпляра:
```rust
let player2 = Player {
    name: String::from("Иван"),
    ..player  // остальные поля из player (move!)
};
```

**[[Функции|Методы]]** — `impl` блок:
```rust
impl Player {
    // Метод — первый аргумент всегда self
    fn status(&self) -> &str {
        if self.hp > 50 { "здоров" }
        else if self.hp > 0 { "ранен" }
        else { "мёртв" }
    }

    fn take_damage(&mut self, dmg: i32) {
        self.hp = (self.hp - dmg).max(0);
    }

    // Ассоциированная функция (без self) — вызов через ::
    fn new(name: &str) -> Player {
        Player {
            name: String::from(name),
            hp: 100,
            level: 1,
            is_alive: true,
        }
    }
}

let mut p = Player::new("Артём"); // :: — как конструктор
p.take_damage(30);
println!("{}", p.status());
```
`&self` — читаем, `&mut self` — изменяем, `self` — забираем владение.

**Tuple structs** — когда имена полей не нужны:
```rust
struct Point(f64, f64);
struct Color(u8, u8, u8);

let pos = Point(1.0, 2.5);
println!("{}", pos.0);
```
