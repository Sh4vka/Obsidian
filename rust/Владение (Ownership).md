**Стек и куча — почему это важно:**

[[Типы данных]] `i32`, `bool`, `f64`, `char`, tuple и array из них — живут в **стеке**. Копируются автоматически, дёшево.

`String`, `Vec` и другие динамические типы — живут в **куче**. Копировать дорого, поэтому Rust по умолчанию **перемещает** их.

**Move** — передача владения:
```rust 
let s1 = String::from("hello");
let s2 = s1; // s1 больше не существует — владение перешло к s2

println!("{}", s1); // ошибка компиляции: value moved
println!("{}", s2); 
```
Rust просто объявляет `s1` недействительным.

**Clone** — явное глубокое копирование:
```rust 
let s1 = String::from("hello");
let s2 = s1.clone(); // копия данных в куче

println!("{} {}", s1, s2); // оба живы
```

Copy-типы — стековые значения копируются автоматически:
```rust
let x = 5;
let y = x; // копия, не move

println!("{} {}", x, y); // i32 реализует трейт Copy
```
`i32`, `f64`, `bool`, `char`, tuple из Copy-типов — всё это Copy. `String` — нет.

**Владение и [[Функции]]**:
```rust 
fn print_name(s: String) {       // s получает владение
    println!("{}", s);
}                                // s удаляется здесь

let name = String::from("Артём");
print_name(name);                // владение передано в функцию
println!("{}", name);            // ошибка: value moved
```

Чтобы не передавать владение — используют **ссылки**:
```rust
fn print_name(s: &String) {      // берём ссылку, не владение
    println!("{}", s);
}

let name = String::from("Артём");
print_name(&name);               // передаём ссылку
println!("{}", name);            // name живёт
```

`&` — неизменяемая ссылка (borrow). `&mut` — изменяемая:
```rust
fn add_title(s: &mut String) {
    s.push_str(", Герой");
}

let mut name = String::from("Артём");
add_title(&mut name);
println!("{}", name); // "Артём, Герой"
```
см. [[Переменные и изменяемость]]

**Правила ссылок — компилятор следит строго:**
- Одновременно: сколько угодно `&` **или** ровно одна `&mut`
- Ссылка не может пережить владельца
