Функции в Rust объявляются через `fn`. Имена — `snake_case`. Порядок объявления в файле не важен — можно вызвать функцию до её определения.

Пример:
```rust
fn greet() {
    println!("Привет!");
}
```

**Параметры** — тип указывается обязательно, без исключений:
```rust 
fn greet(name: &str, level: i32) {
    println!("{} (уровень {})", name, level);
}
```

**Возвращаемое значение** — тип после `->`.
```rust
fn add(a: i32, b: i32) -> i32 {
    a + b  // без точки с запятой
}
```

В Rust различают **выражения** и **инструкции**:

- `a + b` — выражение, возвращает значение
- `a + b;` — инструкция (с `;`), возвращает `()` — пустой тип

Блок как выражение:
```rust
let damage = {
    let base = 10;
    let bonus = 5;
    base + bonus // без ; — значение блока
};
// damage == 15
```
