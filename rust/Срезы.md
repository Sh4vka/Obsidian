Срез (`slice`) — это **ссылка на часть коллекции** без копирования данных. Не [[Владение (Ownership)|владеет]] данными, только смотрит на них.
Строковый срез `&str`:
```rust
let s = String::from("Goblin King");

let first = &s[0..6];   // "Goblin"
let second = &s[7..11]; // "King"
let all = &s[..];       // весь String как &str
```

`&str` — это и есть срез строки. Строковые литералы `"hello"` — тоже `&str`, они живут в бинарнике программы.
```rust
let literal: &str = "hello"; // ссылка на данные в бинарнике
let owned: String = String::from("hello"); // данные в куче
```

Поэтому [[Функции|функции]] лучше принимать `&str` чем `&String` — работает с обоими:
```rust
fn greet(name: &str) { println!("Привет, {}!", name); }

greet("Артём");                        // &str напрямую
greet(&String::from("Артём"));         // &String → &str автоматически
```

**Срез массива**:
```rust
let arr = [10, 20, 30, 40, 50];

let slice: &[i32] = &arr[1..4]; // [20, 30, 40]
println!("{}", slice.len());    // 3
println!("{}", slice[0]);       // 20
```
Тип среза массива — `&[T]`, где `T` — [[Типы данных|тип элементов]].

**Срезы и [[Владение (Ownership)|владение]]:**
Срез — это borrowed ссылка. Пока срез жив, оригинал нельзя изменять:
```rust
let mut s = String::from("hello world");
let word = &s[0..5];     // срез живёт...
s.clear();               // нельзя: word ещё используется ниже
println!("{}", word);
```
Компилятор поймает это — одна из главных защит Rust от dangling pointers.
