Переменные по умолчанию неизменяемы
`let x = 5;`

Изменяемость:
`let mut x = 5;`

#Константы:
`const MAX_IN: u32 = 100000;`
Важно указать тип. Вычисляемо на этапе компиляции.

#shadowing - переобъявление переменной
```rust
let x = 5;
let x = x + 1;
let x = x * 2;
```
#shadowing не mut. Можно изменить тип.
```rust
let space = " "; 
let space = space.len();
```
