
`if` в Rust — выражение, значит его можно присвоить:
```rust
let msg = if hp > 0 { "жив" } else { "мёртв" };
```
Типы в обеих ветках должны совпадать — иначе ошибка компиляции.

`loop` — бесконечный цикл:
```rust
let mut count = 0;
let result = loop {
    count += 1;
    if count == 5 {
        break count * 2; // loop тоже выражение — возвращает значение через break
    }
};
// result == 10
```

`while` — пока условие истинно:
```rust 
let mut hp = 100;
while hp > 0 {
    hp -= 30;
    println!("HP: {}", hp);
}
```

`for` — основной цикл в Rust:
```rust
// По диапазону
for i in 0..5 {        // 0, 1, 2, 3, 4 — конец не включён
    println!("{}", i);
}
for i in 0..=5 {       // 0, 1, 2, 3, 4, 5 — конец включён
    println!("{}", i);
}

// По коллекции
let items = ["меч", "щит", "зелье"];
for item in items {
    println!("{}", item);
}

// С индексом
for (i, item) in items.iter().enumerate() {
    println!("{}: {}", i, item);
}
```

`match` — мощная замена switch:
```rust 
let hp = 30;
match hp {
    0           => println!("мёртв"),
    1..=30      => println!("критично"),
    31..=70     => println!("ранен"),
    _           => println!("здоров"), // _ = любое другое значение
}
```
`match` обязан покрывать **все** возможные значения — компилятор проверяет. `_` — это "всё остальное".
