Базовый enum:
```rust
enum Direction {
    North,
    South,
    East,
    West,
}

let dir = Direction::North;
```

Enum с [[Типы данных|данными]]:
```rust
enum Enemy {
    Goblin { hp: i32, level: u32 },   // struct-like
    Dragon(String, i32),               // tuple-like
    Boss,                              // unit (без данных)
}

let e1 = Enemy::Goblin { hp: 30, level: 2 };
let e2 = Enemy::Dragon(String::from("Smaug"), 500);
let e3 = Enemy::Boss;
```

[[Управляющие конструкции|match]] с enum:
```rust
match enemy {
    Enemy::Goblin { hp, level } => println!("Goblin lv{} hp{}", level, hp),
    Enemy::Dragon(name, hp)     => println!("Dragon {} hp{}", name, hp),
    Enemy::Boss                 => println!("Boss появился!"),
}
```

`Option<T>` — enum из стандартной библиотеки:
```rust
enum Option<T> {
    Some(T),  // есть значение
    None,     // нет значения
}
```

```rust
fn find_item(inventory: &[&str], target: &str) -> Option<usize> {
    for (i, &item) in inventory.iter().enumerate() {
        if item == target {
            return Some(i);
        }
    }
    None
}

let inv = ["sword", "shield", "potion"];
match find_item(&inv, "shield") {
    Some(i) => println!("Найдено на позиции {}", i),
    None    => println!("Не найдено"),
}
```

Удобные методы `Option`:
```rust
let x: Option<i32> = Some(42);
let y: Option<i32> = None;

x.unwrap()              // 42, паникует если None — использовать осторожно
x.unwrap_or(0)          // 42, или дефолт если None
x.is_some()             // true
y.is_none()             // true
if let Some(val) = x { println!("{}", val); } // удобный синтаксис
```

`Result<T, E>` — enum для обработки ошибок:
```rust
enum Result<T, E> {
    Ok(T),   // успех с значением
    Err(E),  // ошибка с описанием
}
```

```rust
fn parse_hp(s: &str) -> Result<i32, String> {
    match s.parse::<i32>() {
        Ok(n) if n > 0 => Ok(n),
        Ok(_)          => Err(String::from("HP должен быть положительным")),
        Err(_)         => Err(String::from("Не число")),
    }
}

match parse_hp("75") {
    Ok(hp)  => println!("HP: {}", hp),
    Err(e)  => println!("Ошибка: {}", e),
}
```
`Option` и `Result` — везде в Rust. Они заменяют null и исключения.
